# Фотосалон «Объектив»

Сайт с заказом печати фото, конструктором футболок, личным кабинетом и админкой.

## Как стать администратором

Админ входит на сайт как обычный клиент — со своим номером телефона и паролем — и видит пункт «Админка».

**Дальше** других сотрудников можно добавлять без терминала: «Настройки» → «Администраторы» → ввести номер (человек должен быть зарегистрирован).

Логин `admin` с паролем из терминала остаётся запасным входом. Сбросить его пароль: `cd /var/www/obektiv && sudo -u nodejs DATA_DIR=/var/lib/obektiv node deploy/reset-admin.js НовыйПароль`.

## Проверка данных

При регистрации и оформлении заказа сайт проверяет данные сразу при вводе и ещё раз на сервере:
- **телефон** — только российский мобильный (+7 9…), без «900 123-45-67» и «999 999-99-99»; поле само форматирует номер;
- **имя** — только буквы, без цифр, ссылок, мата и наборов вроде «фыва», «asdf», «test»; первая буква становится заглавной;
- **пароль** — от 6 символов, не «123456», «qwerty» и т.п.;
- **комментарий** — без ссылок;
- скрытая ловушка для ботов.

**Подтверждение номера (по желанию)** — единственный способ убедиться, что номер настоящий и принадлежит человеку. «Настройки» → «Подтверждение номера при регистрации», выберите способ:
- **Звонок** (SMS.ru) — самый дешёвый: сервис звонит и сбрасывает, код — последние 4 цифры входящего номера;
- **SMS** (SMS.ru);
- **WhatsApp** или **MAX** (GREEN-API) — код приходит сообщением с телефона салона. Для этого лучше отдельный номер.

Для SMS.ru нужен api_id из личного кабинета, для GREEN-API — apiUrl, idInstance и apiTokenInstance. Подробные шаги — прямо в админке под каждым способом.

## Поиск и превью ссылок

Сайт сам отдаёт Яндексу и Google для каждой страницы свой заголовок, описание и текст, а мессенджерам — картинку превью. Есть карта сайта `/sitemap.xml` и `/robots.txt`.

Что настроить в админке:
- «Настройки» → «Поиск и превью ссылок»: город (добавится в заголовки: «Печать фото в Казани»), описание сайта, своя картинка превью (иначе стандартная с узором).
- У каждой услуги в редакторе есть блок «Как услуга выглядит в поиске» с живым предпросмотром. Картинка превью для услуги — её обложка.

Чтобы сайт появился в поиске:
1. Зайдите на webmaster.yandex.ru → «Добавить сайт» → способ подтверждения «Мета-тег». Скопируйте из тега только значение `content` и вставьте в «Настройки» → «Код Яндекс Вебмастера». Сохраните и нажмите «Проверить» в Вебмастере.
2. В Вебмастере: «Индексирование» → «Файлы Sitemap» → добавьте `ваш-сайт/sitemap.xml`.
3. То же в Google Search Console (search.google.com/search-console): способ «HTML-тег» → поле «Код Google Search Console», затем раздел «Файлы Sitemap».
4. Добавьте салон в Яндекс Бизнес и Google Business Profile — так он появится на картах.

## Запуск на своём компьютере

1. Установите Node.js версии 22.13 или новее: https://nodejs.org (кнопка LTS).
2. Распакуйте архив, откройте папку в терминале и выполните:

   ```
   node server.js
   ```

3. Откройте в браузере http://localhost:3000

Больше ничего ставить не нужно: база данных встроена в Node.js.

При **первом** запуске в терминале появится пароль администратора:

```
  Логин:  admin
  Пароль: 3f9a1c0b2e
```

Сохраните его. Войдите на сайте (значок человечка → логин `admin`), затем смените пароль в личном кабинете. Админка открывается по адресу `/admin`.

Задать пароль заранее можно так: `ADMIN_PASSWORD=мойпароль node server.js`.

## Где что хранится

Всё лежит в папке `data/`:
- `obektiv.db` — база: пользователи, заказы, услуги, настройки;
- `uploads/` — все загруженные фото.

**Делайте копию папки `data/` регулярно** — это все ваши заказы. Фото, которые клиент загрузил, но так и не оформил заказ, удаляются сами через сутки.

## Первая настройка (админка → «Настройки»)

- **Салон и контакты**: адрес, телефон, часы, ссылка на карту, соцсети, заголовок главной, 2 фото для главной.
- **Цены**: форматы печати (название, размер в см, цена), доплата за бумагу, скидка «каждый N-й отпечаток − X%», доплаты за размеры футболок.

Цена отпечатка = цена формата + доплата за бумагу. Цены на сайте пересчитываются сразу после сохранения. Пока вы не сохраните свои цены и контакты, админка показывает напоминание.

## Скидка на каждый 6-й отпечаток

Считаются все отпечатки клиента во всех его заказах печати (кроме отменённых). Каждый 6-й, 12-й, 18-й… отпечаток стоит на 10% дешевле. Если отменить заказ, его отпечатки перестают учитываться в следующих заказах. Число и процент меняются в настройках; 0 — скидка выключена.

## Услуги (конструктор страниц)

Админка → «Услуги» → «Новая услуга». Страница собирается из блоков: заголовок, текст, фото, галерея, прайс, вопросы-ответы, выделенный блок, таблица цен на печать (подставляется из настроек сама). Блоки можно двигать стрелками, есть предпросмотр.

Поле «Кнопка на странице»:
- **Без кнопки** — обычная информационная услуга (фото на документы, фотосессия и т.п.);
- **Заказать печать** — кнопка ведёт в конструктор печати;
- **Открыть конструктор футболок** — кнопка ведёт к футболкам.

Порядок услуг в списке = порядок на главной. Услуга с печатью показывается на главной крупной карточкой.

## Футболки (3D-конструктор)

Клиент крутит 3D-футболку, загружает сколько угодно картинок и клеит их куда хочет: на грудь, спину или рукава (рукава — это края переда и спины). Картинки можно двигать пальцем, увеличивать и поворачивать (двумя пальцами или ползунками). Сайт сразу показывает примерный размер каждой картинки в сантиметрах.

Админка → «Футболки» → «Новая модель»: название, фасон (футболка, оверсайз, лонгслив), цвет, цена и размеры в наличии. Фотографии не нужны — футболка рисуется сама, справа видно, как её увидит клиент. Каждый цвет — отдельная модель.

Доплата за каждую картинку после первой задаётся в «Настройках» (0 — сколько угодно картинок за одну цену).

В заказе футболки приходит макет со всех сторон, где есть картинки, и сами картинки в исходном качестве. В архиве они подписаны: `zakaz-12_naklejka-1_pered_22x17sm.png` — первая картинка, на перед, примерно 22×17 см.

## Заказы

Админка → «Заказы». Новые заказы появляются сами (проверка раз в 30 секунд). В каждом заказе:
- телефон клиента с кнопкой звонка;
- сводка «что печатать», например «10×15, матовая: 12 шт.»;
- скачивание каждого файла или всех сразу архивом ZIP. Имена файлов подсказывают параметры: `zakaz-12_03_10x15_matte_x2.jpg` = заказ 12, фото 3, формат 10×15, матовая, 2 копии;
- для футболок — оригинал картинки и готовый макет;
- статус (новый → в работе → готов → выдан) — клиент видит его в личном кабинете.

## Размещение на Beget

Нужен **VPS** с готовым решением **Node.js** (Облако → Создать сервер → Маркетплейс → Node.js). Обычный виртуальный хостинг Beget не подойдёт: там Node.js работает в урезанном режиме, загрузка фото не заработает.

При создании сервера выберите домен (или бесплатный адрес *.beget.app) — сертификат HTTPS Beget выпустит сам. Хватит самой младшей конфигурации.

### Первая установка (один раз)

1. Загрузите `obektiv.zip` на сервер в папку `/root`. Проще всего программой FileZilla: протокол SFTP, адрес — IP сервера, логин `root`, пароль из панели Beget.
2. Подключитесь к серверу по SSH (на Windows и Mac: открыть «Терминал» и ввести `ssh root@IP-сервера`) и выполните:

   ```
   unzip -o /root/obektiv.zip -d /root && bash /root/obektiv/deploy/install.sh
   ```

3. В конце появится пароль администратора — сохраните его. Сайт уже открывается по вашему домену.

Скрипт сам: отключает тестовое приложение Beget, запускает сайт через PM2 (включится сам после перезагрузки сервера), настраивает nginx для больших фото и включает ежедневную резервную копию.

### Обновление сайта

1. Загрузите новый `obektiv.zip` в `/root` (с заменой старого).
2. Выполните одну команду:

   ```
   obektiv-update
   ```

Заказы, фото клиентов, услуги, цены и настройки лежат отдельно от кода — в `/var/lib/obektiv` — и при обновлении **не трогаются**. Папку `data` из архива переносить не нужно.

### Резервные копии

Каждую ночь в `/var/backups/obektiv` сохраняется архив с базой и всеми фото; хранятся последние 14. Сделать копию вручную: `bash /var/www/obektiv/deploy/backup.sh`. Скачать её можно той же FileZilla. Дополнительно в панели Beget есть автоматические бэкапы всего сервера.

### Если что-то не так

- Посмотреть ошибки: `sudo -u nodejs pm2 logs obektiv`
- Перезапустить сайт: `sudo -u nodejs pm2 restart obektiv`
- Забыли пароль админа: `cd /var/www/obektiv && sudo -u nodejs DATA_DIR=/var/lib/obektiv node deploy/reset-admin.js новыйпароль`

## Красивая ссылка: свой домен

Адрес `*.beget.app` технический. Свой домен (например `obektiv-foto.ru`) стоит примерно несколько сотен рублей в год.

1. **Купите домен** в разделе «Домены» Beget.
2. **Направьте его на сервер.** В DNS домена (в том же разделе Beget, «DNS-записи») добавьте A-запись: имя `@` → IP сервера `IP-сервера`, и такую же запись для `www`. Изменения работают от 10 минут до нескольких часов.
3. **Подключите на сервере** (в PowerShell, после `ssh root@IP-сервера`):
   ```
   bash /var/www/obektiv/deploy/set-domain.sh obektiv-foto.ru
   ```
   Скрипт проверит DNS, выпустит бесплатный HTTPS-сертификат, включит переход с http на https и подскажет новый адрес сайта. Старый адрес `beget.app` тоже продолжит работать.
4. **Добавьте новый адрес в поиск:** Яндекс Вебмастер и Google Search Console, как описано выше.

Если скрипт пишет, что домен указывает не на тот IP, значит DNS ещё не обновился: подождите и запустите снова. Запускать его можно сколько угодно раз.

## Запуск на другом хостинге

Подойдёт любой VPS с Node.js 22+ и постоянным диском. Запуск: `pm2 start deploy/ecosystem.config.js`. Перед сайтом нужен nginx с `client_max_body_size 64m;`, `proxy_set_header Host $host;` и `proxy_set_header X-Forwarded-Proto $scheme;`.

Переменные окружения: `PORT` (по умолчанию 3000), `DATA_DIR` (папка данных), `ADMIN_PASSWORD` (пароль админа при первом запуске).

## Структура проекта

```
server.js            — сервер: API, вход, загрузка файлов, заказы, админка
lib/db.js            — база данных и значения по умолчанию
lib/zip.js           — архивы для скачивания заказов
public/index.html    — страница сайта
public/css/style.css — оформление (цвета — в начале файла)
public/js/app.js     — сайт: главная, услуги, печать, футболки, кабинет
public/js/admin.js   — админка
public/js/pricing.js — расчёт цен (общий для сайта и сервера)
public/js/tee3d.js   — 3D-футболка (WebGL, без внешних библиотек)
lib/seo.js           — заголовки, описания и превью для поиска и мессенджеров
public/img/          — логотип и шаблоны футболок
deploy/              — установка, обновление и резервные копии на сервере
```

Шрифты меняются в админке: «Настройки» → «Шрифты». Есть список из 23 шрифтов для заголовков и 17 для текста, все с кириллицей, с предпросмотром. Можно вписать и любой другой шрифт с fonts.google.com. По умолчанию — Montserrat Alternates и Manrope.

Логотип — файлы public/img/logo.svg (плашка для шапки), logo-word-lime.svg (подвал), logo-mark.svg (значок вкладки). Если поменяете название салона в настройках, логотип останется «объектив» — его нужно будет перерисовать.
